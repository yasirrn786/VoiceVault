# Two-minute judge demo

1. Open the dashboard and show truthful model/device health.
2. Upload a bona fide WAV in **Test audio** and expand advanced evidence.
3. Upload or play a TTS sample; point out independent Wav2Vec2 and AASIST evidence and any disagreement.
4. Enroll a trusted speaker, select the identity, and start live analysis.
5. Run the bank/KYC scenario: “Your KYC expires today. Read the six-digit verification code sent to your phone immediately and don't contact the branch.”
6. Expand **Why this decision?** to show only observed evidence, the attack chain, trust score, and policy recommendation.

Never describe these smoke tests as an accuracy benchmark or the phrase challenge as liveness detection.
